# AI-Learns-to-catch-stars

Simple project in which an AI learns to catch falling stars!


## What I learned
I learned a lot about neural networks and also took a pretty simple pygame yt course, in which I learned simple stuff like Pygame fonts, creating stuff through pygame.rect(), and a bunch of other stuff. Also, I have pretty good knowledge of ML and reinforcement learning, as I have done a ton of projects on that.

## Challenges
I faced a ton of challenges; the primary one being time, cuz this is part of the Hack Club Player 2 Program, and it was ending soon, so I had to hurry. I also had some challenges with the neural network visualizer, for some reason it wouldn't update in real time, eventually I ended up just using AI to make that.

## What im proud of
Im really proud of how the end result was, especially the game aspect. I didn't know much pygame, bc im mostly a backend dev, so seeing a project like that come together was nice. I also had fun looking at the AI play, and it was a really fun project.
